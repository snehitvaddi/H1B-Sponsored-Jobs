# Contributing

This list is generated automatically twice a day, but the useful corrections come
from people actually applying.

## A role has closed

Open an [issue](../../issues/new?template=closed.yml) with the apply link, or send
a PR removing the row from `data/listings.json`. Either is fine; the issue is faster.

We do **not** monitor these roles for closure ourselves — the list is point-in-time,
and it stays honest because people report what they find.

## Something looks wrong

Wrong company name, a non-US role, a role that turned out not to sponsor — open an
issue. Sponsorship history is checked against USCIS filings for the *employer*, so a
specific req having no sponsorship budget is entirely possible and worth reporting.

## Using this data

Go ahead. It is [CC0](LICENSE) — scrape it, fork it, build a bot on it, send email
digests from it. If you build something, open an issue and we will link to it here.

The live JSON endpoint is `https://applyloop.pro/api/public/h1b-jobs` if you would
rather not scrape GitHub.
